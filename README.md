# Рейтинг достижений

Локальное многопользовательское Flask-приложение с общей базой SQLite. Поддерживает карточки достижений, сводные реестры детей и педагогов, рейтинг, вложения, публикации, Excel/Word, роли, аудит, личные кабинеты детей и адресные приглашения на конкурсы.

DeepSeek используется для автоматического определения направления и генерации поздравлений. Ключ, адрес API и модель читаются из переменных окружения `DEEPSEEK_API_KEY`, `DEEPSEEK_API_URL` и `DEEPSEEK_MODEL`. При недоступности API направление определяется локальными правилами, а шаблон поздравления остаётся доступен.

При генерации поздравления сведения из карточки, включая ФИО ребёнка и педагога, передаются внешнему API. Используйте функцию только при наличии необходимых согласий на обработку персональных данных.

Подробное пошаговое руководство для сотрудников и администратора находится на рабочем столе в папке `БАНК ДАННЫХ ОДАРЕННОСТИ`.

## ВАЖНО: смените стандартный пароль

При первом запуске создаётся администратор **`admin` / `admin123`**. Это публично известный пароль. Сразу после входа откройте «Пользователи» и задайте администратору новый пароль. Для развёртывания также установите случайный `SECRET_KEY` в переменных окружения.

## Запуск

1. Запустите `run.bat` или выполните `python -m pip install -r requirements.txt`, затем `python app.py`.
2. На компьютере с программой откройте единую страницу входа <http://127.0.0.1:5000/login>.
3. На других компьютерах той же локальной сети откройте `http://IP-АДРЕС-СЕРВЕРА:5000`. При первом запуске разрешите Python доступ в брандмауэре Windows.
4. Войдите как `admin` / `admin123` и смените пароль.

## Развёртывание на Render

Репозиторий содержит `render.yaml` для развёртывания через Render Blueprint. База и вложения хранятся на постоянном диске `/var/data` и не публикуются в Git. После первого запуска обязательно войдите как `admin` / `admin123` и смените пароль администратора.

На общей странице входа выберите профиль «Организатор» или «Ребёнок». После авторизации сотрудник попадает в административную часть, ребёнок — в личный кабинет. Для демонстрации создаётся детский профиль **`student` / `student123`**, связанный с записью «Иванова Мария Сергеевна» из «Школа № 1». Демо-кабинет и одна возможность создаются только тогда, когда соответствующие таблицы пусты.

База `achievements.db` и папка `uploads` создаются автоматически рядом с `app.py`. При первой инициализации добавляются три записи с заметной меткой «Демо». Их можно изменить или удалить.

## Роли

- `admin`: все операции, пользователи, аудит и резервная копия SQLite.
- `editor`: создание, изменение и удаление достижений.
- `viewer`: просмотр реестров и экспорт.

Администратор управляет личными кабинетами в разделе «Кабинеты»: создаёт точную привязку к ФИО и организации, меняет данные, отключает вход и задаёт новый пароль. Пароли в интерфейсе не отображаются. Администратор и редактор создают и редактируют возможности; наблюдатель может их просматривать.

При сохранении активной возможности приглашения автоматически получают активные кабинеты детей, у которых есть хотя бы одно достижение того же направления с точным совпадением ФИО и организации. При создании кабинета подходящие активные возможности добавляются задним числом. Повторные приглашения блокируются ограничением базы данных.

Одна запись соответствует одному участнику команды. Для каждого следующего участника создайте отдельную запись. Совпадающие ФИО автоматически объединяются в реестрах.

## Безопасность и данные

- Пароли хешируются PBKDF2 средствами Werkzeug.
- Сессии сотрудников и детей разделены; кабинет ребёнка не предоставляет доступ к маршрутам сотрудников.
- Изменяющие запросы защищены CSRF-токеном.
- Имена вложений нормализуются, реальные имена генерируются случайно; разрешены PNG, JPG, WEBP, PDF, DOC/DOCX, XLS/XLSX.
- Общий предел одного запроса с файлами: 16 МБ.
- Перед переносом восстановите файл резервной копии как `achievements.db` при остановленном приложении.

Приложение по умолчанию слушает локальную сеть (`0.0.0.0`). Для публикации в интернете используйте отдельный сервер, случайный `SECRET_KEY`, обратный прокси и HTTPS.
